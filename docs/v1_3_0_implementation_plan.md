# Meta Description Generator v1.3.0 詳細実装計画

## 概要
v1.3.0 では、作業効率を劇的に向上させるための「一括生成」機能と、出力の質を安定させるための「カスタムプロンプトテンプレート」機能を実装します。

---

## 変更内容

### 1. 一括生成 (Bulk Processing) モード
複数のURLに対して、一括でディスクリプションを生成可能にします。

- **UI (main.py)**:
    - 新しいタブ「一括生成」を追加。
    - 複数URLを入力できるテキストエリアを設置。
    - 生成進捗を表示するプログレスバーまたはステータス表示。
- **ロジック (main.py / core_logic.py)**:
    - 入力されたURLをパースし、非同期または逐次処理で内容取得と生成を実行。
    - エラー発生時のスキップ機能と、成功分の一括保存/エクスポート。
    - Gemini API のレート制限を考慮した間隔（スリープ）の導入。

### 2. カスタムプロンプト・テンプレート
よく使う指示（例：ターゲット層、必須条件）を保存し、簡単に呼び出せるようにします。

- **UI (main.py)**:
    - 共通指示入力欄の横に「テンプレート」ドロップダウンを追加。
    - テンプレートの追加・編集・削除を行う管理ダイアログ。
- **データ管理**:
    - `page.client_storage` を使用し、テンプレート名とプロンプト内容を JSON 形式で保存。
- **適用ロジック**:
    - ドロップダウン選択時に、現在の共通指示欄に内容を反映。

## 検証計画

### 1. 機能テスト
- **一括生成**: 5〜10件程度のURLを同時に入力し、すべての結果が正常に生成され、CSVに一括保存されるか。
- **テンプレート**: 新規作成したテンプレートが保存され、再起動後も正しく呼び出せるか。

### 2. 負荷・制限テスト
- URL fetch 失敗時のエラーハンドリングが適切か（途中で止まらないか）。
- 短時間に大量の API 呼び出しを行った際の挙動確認。
